# The Impossible Button

A tiny front-end game built with plain HTML, CSS, and JavaScript. Your goal is simple: click the button—but every click makes it leap to a far-away location.

## Features

- Every button press moves it a substantial distance, so it cannot be clicked twice in the same place.
- After ten escapes, the button says, “alright alright i will let you click me once.” The next press is accepted briefly before the game restarts.
- Dark mode and Reset give the player control over the experience.
- Smooth CSS transitions, responsive layout, and a playful city-night visual style.
